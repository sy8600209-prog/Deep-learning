# 🧠 Deep Learning Experiments & Architectures

Welcome to my deep learning repository! As a B.Tech Computer Science student specializing in Artificial Intelligence and Machine Learning, I created this workspace to document my hands-on progression from foundational neural networks to advanced deep learning architectures. 

This repository contains my implementations, mathematical experiments, and model deployments.

## 📂 Repository Structure

The repository is organized sequentially to reflect the learning path of neural network complexities:

### 1. `/01_Perceptron`
The fundamental building block of all neural networks.
* **Concepts:** Single-layer perceptron logic, linear separability, binary classification, and basic activation functions.
* **Objective:** Understanding how a single artificial neuron processes inputs, applies weights, and makes decisions.

### 2. `/02_ANN` (Artificial Neural Networks)
Scaling the perceptron into multi-layer dense architectures to learn non-linear relationships.
* **Concepts:** Feedforward networks, backpropagation, gradient descent, loss functions, and optimizers.
* **Objective:** Building fully connected networks for tabular data classification and regression tasks.

### 3. `/03_CNN` (Convolutional Neural Networks)
Deep learning architectures specialized for computer vision, feature extraction, and spatial data.
* **Concepts:** Convolutional layers, max/average pooling, stride, padding, and feature map visualization.
* **Objective:** Utilizing frameworks for image preprocessing, complex vision tasks, and foundational work for advanced projects like 3D point cloud generation and satellite image registration.

### 4. `/04_RNN` (Recurrent Neural Networks)
Networks designed to process sequential data and time-series.
* **Concepts:** Sequence modeling, hidden states, context retention, and addressing vanishing gradients.
* **Objective:** Analyzing time-dependent patterns where the sequential order of data points is critical.
